# КМ — скелет

Гамифицированный трекер прогулок с туманом войны. Скелет под дизайн
«Design map 1.1»: карта открывается по мере ходьбы, за это капают XP,
уровни, стрик и ачивки.

**Что это и что это не.** Это не MVP, а стенд для проверки трёх вещей,
на которых такие приложения ломаются: производительность тумана, качество
фоновой геолокации и стоимость учёта покрытия. Экраны «Ачивки», «Места»
и «Профиль» сделаны ровно настолько, чтобы данные было видно.

Бэкенда нет. Всё живёт в SQLite на устройстве.

## Быстрый старт

```bash
npm install
```

```bash
npm test
```

Тесты гоняют чистую логику (Меркатор, H3, фильтр GPS, XP, стрик, ачивки,
восход/закат) без эмулятора — 43 теста за полсекунды.

Для запуска на устройстве нужен **dev build**: MapLibre, Skia и op-sqlite —
нативные модули, в Expo Go они не работают.

```bash
npx expo prebuild --clean
```

```bash
npm run android
```

Проверить, что бандл собирается, можно и без устройства:

```bash
npx expo export --platform android --no-bytecode --output-dir .export-check
```

## iPhone: запуск на бесплатном аккаунте

Платить Apple $99 не нужно, пока приложение не уходит в стор. Хватает Mac
с Xcode из App Store и обычного Apple ID — того же, что на телефоне.

Подключите iPhone кабелем, разблокируйте, нажмите на нём «Доверять этому
компьютеру» — и одна команда:

```bash
npm run setup:ios
```

Скрипт (`scripts/setup-ios.sh`) проверяет окружение, ставит зависимости
(CocoaPods в том числе, если есть Homebrew), генерирует `ios/` и собирает
приложение на телефоне. Ручными остаются четыре шага — автоматизировать их
нельзя, но скрипт предупреждает про каждый в нужный момент и не даёт узнать
о проблеме после двадцати минут установки:

1. Xcode из App Store.
2. Вход в Apple ID: Xcode → Settings → Accounts → «+», затем
   «Manage Certificates…» → «+» → «Apple Development». Одного входа мало,
   сертификат нужно выпустить явно, иначе подписывать сборку нечем.
   Если он выпущен, но недействителен (`security find-identity` показывает
   `1 identities found / 0 valid`) — в связке ключей не хватает
   промежуточных сертификатов Apple, скрипт доставит их сам.
3. «Режим разработчика» на телефоне: Настройки → Конфиденциальность
   и безопасность. Пункт появляется только после первой попытки установки.
4. Доверие сертификату после установки: Настройки → Основные → VPN
   и управление устройством.

Папки `ios/` в репозитории нет намеренно: она целиком выводится из
`app.json` и `package.json`, а в гите давала бы конфликт на каждом
изменении конфига.

Цена бесплатной подписи: сборка перестаёт запускаться через 7 дней, и на
устройстве живёт не больше трёх таких приложений. Лечится повторным
`npm run setup:ios`. Между пересборками JS-изменения подхватывает
обычный `npx expo start --dev-client` — нативку трогать не нужно.

Два ограничения личного аккаунта уже учтены в конфиге, но их стоит знать,
потому что оба ломают подпись молча и непонятным сообщением:

- **`bundleIdentifier` должен быть уникальным на всю Apple.** `com.example.*`
  давно занят, поэтому в `app.json` стоит `com.kafiberlass.km`.
- **Push-entitlement (`aps-environment`) личному аккаунту не выдаётся.**
  А `expo-notifications` дописывает его в `KM.entitlements` самим фактом
  установки — плагин применяется автолинковкой, в `plugins` его перечислять
  не надо. Поэтому пакет убран из зависимостей (в коде он не использовался).
  Когда дойдут руки до напоминаний про стрик: локальным уведомлениям push
  не нужен, но вычищать entitlement придётся своим config-плагином.

Фоновая геолокация от этого не страдает: `UIBackgroundModes` лежит
в Info.plist, а не в entitlements, и с бесплатной подписью работает.

**Scene life cycle.** `plugins/withSceneLifecycle.js` дописывает в Info.plist
scene-манифест и подключает `EXExpoAppSceneDelegate`. Без этого iOS 27 SDK
не запускает приложение вовсе: процесс стартует и гаснет с «UIScene life
cycle is required for apps built with this SDK» — внешне мгновенный вылет
с чёрным экраном и выходом с кодом 0, без крэш-репорта. Всё нужное в Expo 57
уже есть, шаблон prebuild это просто не подключает; когда догонит — плагин
можно удалить.

Чего на iOS нет: аналога Lockito. Подменять координаты можно либо
GPX-плеером в дев-панели, либо через Xcode — Debug → Simulate Location.

## Что проверять в первую очередь

1. **Откройте вкладку «Карта» → `DEV` в правом верхнем углу → `ПРОИГРАТЬ ×20`.**
   Фикстура — вечерняя прогулка вокруг Чистых прудов, 212 точек, ~2.6 км.
   Карта должна открываться коридором с мягким краем, как в макете.
2. **Подвигайте карту во время проигрывания.** Главный вопрос скелета:
   не отстаёт ли туман от тайлов при панорамировании (см. «Известные риски»).
3. **`ПРОИГРАТЬ МГНОВЕННО`** — весь трек за один тик. Проверяет XP, ачивки
   и стрик, не заставляя ждать анимацию.
4. **`DRY-RUN ФИЛЬТРА`** — покажет, сколько точек отсеялось и почему,
   ничего не записывая в базу.

Внизу карты во время прогулки выводится время сборки геометрии тумана —
это и есть метрика, ради которой скелет написан.

## Ключевое архитектурное решение

**Визуальный туман и учётный туман — разные структуры данных.**

| | Визуальный слой | Учётный слой |
|---|---|---|
| Что | обводка пути толстой линией со скруглениями | множество H3-ячеек res 11 |
| Где | `src/features/fog/` (Skia) | `src/core/geo/coverage.ts` + SQLite |
| Зачем | мягкая «тропа» как в макете | точный процент, XP, будущая серверная валидация |

Так сделано потому, что геометрический путь (`turf.buffer` + `turf.union`
по всей истории) деградирует в ноль за пару месяцев, а рисовать по ячейкам —
значит получить шестиугольные края вместо макета.

**Как туман не тормозит.** Геометрия строится один раз в локальных метрах
Меркатора. При движении карты меняется только матрица трансформации,
которая считается в воркете Reanimated на UI-потоке
(`cameraMatrixWorklet` в `src/core/geo/mercator.ts`). React при панорамировании
не ре-рендерится, стоимость кадра не зависит от длины истории.

Локальный `origin` (первая точка пользователя) обязателен: абсолютные метры
Меркатора доходят до 2·10⁷, а Skia считает во float32 — на таких величинах
трек начинает дрожать.

Питч карты выключен намеренно: перспектива требует 4×4-матрицы и ломает
постоянную ширину тропы. В макете карта плоская.

## Структура

```
app/                      экраны (expo-router)
  (tabs)/index.tsx        карта + туман + HUD
  dev.tsx                 GPX-плеер
src/core/                 чистая логика, тестируется без эмулятора
  geo/mercator.ts         проекция, матрица камеры (+ воркет-вариант)
  geo/coverage.ts         H3: раскрытие, проценты
  geo/filter.ts           фильтр GPS: точность, дрожание, телепорты
  geo/sun.ts              восход/закат для ачивки «после заката»
  geo/gpx.ts              парсер GPX
  rules/                  XP, уровни, стрик, ачивки — будущий общий пакет с сервером
  db/                     схема, миграции, репозиторий
src/features/
  tracking/               TrackingProvider: 3 реализации
  fog/                    Skia-слой и сборка геометрии
  map/                    обёртка над MapLibre + стиль
  places/                 демо-места
src/store/useWalkStore.ts движок прогулки: единственное место склейки
tests/                    43 теста на core/*
```

Четыре абстракции заложены сразу, чтобы потом не переписывать:
`TrackingProvider` (источник координат), `MapCanvas` (провайдер карты),
поля `updated_at` / `synced_at` + пустая таблица `outbox` (будущий синк),
`src/core/rules/*` без единого импорта из React (переедет на сервер).

## Геолокация: что включено и что купить потом

`src/features/tracking/` содержит три реализации одного интерфейса:

- **`mock.ts`** — GPX-плеер. Инструмент разработки №1.
- **`expoLocation.ts`** — бесплатный вариант, работает из коробки.
- **`transistor.ts`** — обёртка над `react-native-background-geolocation`.
  **Пакет НЕ установлен.** Он платный (~$300/платформа), но
  **в debug-сборках бесплатен без ограничений** — а в сторы вы пока
  не выкладываетесь. Включить:

  ```bash
  npx expo install react-native-background-geolocation && npx expo prebuild --clean
  ```

  Фабрика в `tracking/index.ts` подхватит его автоматически.
  `metro.config.js` подменяет неустановленный пакет пустышкой — без этого
  Metro падает на статическом резолве ещё до запуска кода.

Чего не хватает в `expo-location` и что даёт платная библиотека: детект
остановки (иначе батарея сгорит за вечер), батчинг точек, автоперезапуск
после того, как ОС убила процесс, activity recognition. На Android к этому
добавляются OEM-киллеры (Xiaomi, Huawei, Oppo) — понадобится экран про
отключение оптимизации батареи.

## Как тестировать GPS, не выходя из дома

Три уровня, каждый проверяет своё:

1. **GPX-плеер в дев-панели** — вся JS-логика. Быстро, детерминированно.
2. **[Lockito](https://play.google.com/store/apps/details?id=fr.dvilleneuve.lockito)**
   (Android, бесплатно) + «Выбрать приложение для фиктивных местоположений»
   в настройках разработчика. Подаёт координаты **в систему**, поэтому
   проверяется нативный путь: foreground service, поведение после сворачивания.
   Плеер этого не проверяет.
3. **Реальные прогулки.** Запишите 5–10 GPX разного характера — город, парк,
   поездка на транспорте, потеря сигнала в переходе, «дрожание» у окна дома —
   и положите в `assets/fixtures/`. Набор реальных треков с артефактами приёма
   ценнее любого генератора; на них ловятся баги, которых не бывает в чистых данных.

Демо-фикстура пересобирается детерминированно:

```bash
node scripts/gen-fixture.js
```

## Карта и данные

Тайлы — [OpenFreeMap](https://openfreemap.org) (схема OpenMapTiles),
бесплатно и без ключа. Стиль под палитру макета собран руками
в `src/features/map/style.ts`: тёмно-коричневая земля, бирюзовая сетка улиц,
подписи выключены.

OpenFreeMap живёт на пожертвованиях и SLA не даёт. Когда понадобится
независимость: `planetiler` собирает экстракт с Geofabrik в один `.pmtiles`,
файл кладётся на Cloudflare R2 (free tier: 10 ГБ, egress бесплатный),
меняется одна константа `TILE_SOURCE_URL`.

Данные OSM под **ODbL** — атрибуция «© OpenStreetMap contributors»
обязательна и включена в стиль. Не снимайте её.

## Известные риски и чего тут нет

**Отставание тумана при панорамировании.** Матрица обновляется из событий
`onRegionIsChanging` MapLibre, а они не гарантированно приходят каждый кадр.
Если на устройстве будет заметный лаг — это главная вещь, которую надо
померить. Запасной вариант: рисовать туман внутри карты обычным `FillLayer`
по полигонам из `cellsToMultiPolygon` (h3-js умеет это сам, turf не нужен) —
двигается идеально, но края будут шестиугольные и без размытия.

**Шрифты.** В `src/core/theme/tokens.ts` объявлены `Oswald` и `VT323`,
но файлов нет и `expo-font` их не грузит — сейчас используются системные.
Оба шрифта под OFL, скачиваются с Google Fonts, кладутся в `assets/fonts`.

**Чего нет намеренно:** сервера, синхронизации, друзей, лидербордов,
античита, локальных пуш-напоминаний про стрик (логика `isStreakAtRisk`
готова, планировщик не подключён), реальных POI (сейчас 4 демо-места).

**Прогресс живёт только на телефоне.** Смена устройства = потеря истории.
Это осознанный выбор v1: он убирает всю инфраструктуру и заодно снимает
главный риск по приватности — история перемещений никуда не уходит.
